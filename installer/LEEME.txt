Análisis de tamaño de gota - CCTVal
===================================

1. Descomprima el archivo completo.
2. Abra Instalar_DesalinizadorGotas.exe.
3. Pulse Elegir carpeta para seleccionar la ubicación del programa.
4. Pulse Instalar programa y, al finalizar, Abrir programa.

Para actualizar una copia existente, use Elegir carpeta y seleccione la carpeta
que contiene DesalinizadorGotas.exe. Se habilitará Actualizar programa.
El instalador recuerda la ubicación después de instalar o actualizar.
Cierre Análisis de gotas antes de actualizar o desinstalar.

También se crean accesos directos en el escritorio y el menú Inicio.
La ventana permite desinstalar conservando sus imágenes, resultados y otros
archivos personales que haya guardado en la carpeta del programa.

La carpeta predeterminada es:
  %LOCALAPPDATA%\Programs\DesalinizadorGotas
Puede elegir otra carpeta en la que tenga permisos de escritura.

No necesita Python ni conexión a Internet.
instalar.bat es una alternativa para abrir la misma ventana gráfica.
