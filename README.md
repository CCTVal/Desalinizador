# Desalinizador

Este código lee una imagen que corresponda a una foto de la cámara de humidificación del desalinizador y entrega los anchos de las gotas que están en suspensión.

Cualquier duda, por favor dirigirla a Sebastián Vidal, coordinador de este desarrollo.

## Funcionamiento

Para correr el código, ejecutar: ``python gotas.py <ruta_imagen>`` donde el tercer elemento es el nombre del archivo con la foto que se desa analizar. Por ejemplo,

```bash
python gotas.py DSC_0111.JPG
```
